# 🔮 O Mago Quântico

> Um portal colaborativo de artigos, estudos e debates sobre como a consciência, os símbolos e a informação moldam a realidade.

Inspirado na estética limpa e objetiva do TabNews, **O Mago Quântico** reúne ciência de fronteira, filosofia hermética e desenvolvimento pessoal em um ambiente livre de ruídos, algoritmos viciantes e clickbait.

---

## 🌌 O Conceito e o Personagem

O nome une duas forças que parecem opostas, mas falam da mesma essência:

- **O Mago:** Representa o arquétipo do domínio sobre si mesmo e sobre os símbolos. Ele é o observador que compreende as leis da mente e transmuta o caos em ordem.
- **O Quântico:** Representa a visão moderna da realidade como um campo de infinitas possibilidades, energia e informação pura, onde o observador colapsa e altera a função de onda do que é observado.

No portal, o **Mago Quântico** atua como o guia minimalista da comunidade: sem truques ou atalhos, apenas conhecimento profundo e clareza mental para colapsar uma realidade superior.

## 🛠️ Engenharia e Arquitetura

O projeto é desenvolvido com o rigor arquitetural e as melhores práticas do [curso.dev](https://curso.dev):

- **Frontend & Fullstack:** Next.js & React
- **Estilização & Qualidade:** EditorConfig & Prettier
- **Testes Automatizados:** Jest (TDD / Integração)
- **Banco de Dados & Infraestrutura:** PostgreSQL & Docker Compose
- **Controle de Versão & CI/CD:** Git, Conventional Commits e Vercel
- **Ambiente de Desenvolvimento:** WSL 2 (Ubuntu) e Node.js LTS

## 🧪 Como Rodar os Testes

Com o servidor de desenvolvimento ativo (`npm run dev`), execute em outro terminal:

```bash
# Executa todos os testes automatizados
npm test

# Executa os testes no modo vigia contínuo (Modo Arqueiro)
npm run test:watch
```
